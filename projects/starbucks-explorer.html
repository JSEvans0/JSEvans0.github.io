Starbucks Nutrition Explorer

A dashboard that lets other people do the exploring.

  • Python
  • Streamlit
  • Plotly
  • pandas
  • EDA
Code on GitHub

The idea

A notebook is a great place to do analysis and a bad place to hand it to someone else. This project takes the Starbucks menu dataset and wraps it in a small Streamlit app, so a person with no Python can browse the same data, change the view, and reach their own conclusions.

What the app does

The app is organized as four pages behind a sidebar:

  • Home — what the dataset is and how to move around the app.
  • Data Overview — the cleaned table itself, with shape and column details.
  • EDA — the distributions and relationships I thought were worth pointing out.
  • DIY EDA — the part I care about most: pick any two features and the app charts them for you.

Why the DIY page matters. Any dashboard I build reflects the questions I happened to think of. Giving users their own axis pickers means the tool keeps working for questions I never anticipated.

How it was built

  • Cleaned the raw menu data in pandas and saved the result, so the app loads a prepared file rather than re-deriving it on every page view.
  • Built the interface in Streamlit — sidebar navigation, page routing, and widget-driven state.
  • Charted with Plotly rather than static images, so every plot is hoverable and zoomable.

What I’d do differently

The app loads the full dataset on every interaction; caching that read with @st.cache_data is a small change with a real speed payoff. I’d also add a download button for whatever slice the user has filtered to, since “can you send me that as a CSV?” is the question a dashboard always gets next.
